我很高兴地宣布我们发布了 Dalamud API9 的新功能和重大变更的最终列表，计划于 10 月初随 Patch 6.5 一起发布。

此版本包含大量幕后更改，使 Dalamud 更加稳定，并有望为我们未来进一步改进 API 提供机会。

请[在此查看完整的变更列表](/docs/versions-channels)。

## 服务现在变为接口

您会遇到的一个主要变化是，您一直在使用的所有服务现在都通过接口访问，而不是直接通过实现类型。
我们决定走这条路线，因为这为我们提供了机会，逐步将所有服务转换为插件特定的服务——这些服务知道哪些资源分配给哪个插件，并允许我们在出现问题时跟踪和释放它们——并且可以通过可靠的上下文信息（关于哪个插件正在使用它们）增强一些 Dalamud 功能，如命令列表或日志记录 API。

它还可以为改进自动化测试打开大门，并使我们更容易逐步改进 API 和功能。

要迁移，您很可能只需要**在您使用的所有服务名称前加上 I**。就这么简单！

## 关于 ImGui 的说明

我想鼓励大家看看我们通过 `Dalamud.Interface.Utility` 引入到主要 Dalamud 程序集中的精彩新 ImRaii API！
它们让防止您的插件因未处理异常等原因导致的崩溃变得更加容易，而且在我看来，使用起来也更加方便。您再也不会忘记弹出颜色，或者忘记子窗口总是需要结束。
还有一些其他便利的 API，例如用于与表格交互的 API。

另一件您可能想了解的事情是 Dalamud WindowSystem——如果您使用它来创建 ImGui 窗口，它们会自动获得许多良好的用户体验功能，例如通过 Esc 或手柄操作集成到游戏原生的关闭顺序中，以及 UI 音效。我相信您的用户会喜欢的！

## 测试您的插件

这次我们决定不在插件仓库上开放 v9 分支。过去，这导致了很多混乱和混乱的测试期，因为我们往往会在目标补丁发布之前就发布了新 API 级别的插件版本，而这些版本在该版本的游戏上并不稳定。

当然，我们鼓励您现在就本地开始在开发分支中调整您的插件以适应新的 API，以便在补丁到来时做好准备！只需使用 Dalamud 分支切换器（`/xlbranch`）切换到 v9 分支。
