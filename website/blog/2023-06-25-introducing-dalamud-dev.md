大家好！

我们为所有插件开发者带来关于开发者 FAQ 和 Dalamud 文档的快速更新。[Dalamud.dev](https://dalamud.dev) 是我们文档的新家。它将包含我们所有的高级开发者文档，以及近乎实时的 Dalamud XML 文档视图。

我们正在积极地将现有文档迁移到新站点，包括清理现有的开发者 FAQ 并更有效地组织其信息。旧版开发者 FAQ 仍然可以在 [Dalamud.dev](https://dalamud.dev/faq) 上找到，但其内容会随着我们更新和扩展文档而逐渐减少。

如果您想帮助贡献文档，可以通过以下几种方式：

- 针对 [dalamud-docs 仓库](https://github.com/goatcorp/dalamud-docs) 打开 Pull Requests，提交 FAQ 或高级信息。
- 针对 Dalamud 打开 Pull Requests，扩展我们现有的 XML 文档。
- 联系维护者之一，提供关于如何改进文档的评论/建议。

如果您对什么内容应该放在哪里（或者应该记录什么以及如何记录）有疑问，请随时联系维护者。

感谢选择 Dalamud！
