# Dalamud.Interface.GameFonts

> 🌐 本页是 [dalamud.dev/api/Dalamud.Interface.GameFonts/](https://dalamud.dev/api/Dalamud.Interface.GameFonts/) 的中文翻译。
> 类型/方法名称保留英文原文，仅翻译说明文字。

## 类

### FdtReader​

解析游戏字体文件。

### GameFontLayoutPlan​

关于字形如何渲染的计划。

### GameFontLayoutPlan.Builder​

构建一个 GameFontLayoutPlan。

### GameFontLayoutPlan.Element​

关于每个字形如何渲染的计划。

## 结构体

### FdtReader.FdtHeader​

游戏字体文件格式的头部。

### FdtReader.FontTableEntry​

字形表条目。

### FdtReader.FontTableHeader​

字形表的头部。

### FdtReader.KerningTableEntry​

字距调整表条目。

### FdtReader.KerningTableHeader​

字距调整表的头部。

### GameFontStyle​

描述基于游戏资源文件的字体。

## 枚举

### GameFontFamily​

可用游戏字体系列的枚举。

### GameFontFamilyAndSize​

特定大小的可用游戏字体的枚举。

### GameFontLayoutPlan.HorizontalAlignment​

水平对齐。
