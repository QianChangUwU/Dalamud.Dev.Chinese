# Dalamud.Game.Text.SeStringHandling

> 🌐 本页是 [dalamud.dev/api/Dalamud.Game.Text.SeStringHandling/](https://dalamud.dev/api/Dalamud.Game.Text.SeStringHandling/) 的中文翻译。

## 类

### Payload​

这个类表示一个解析后的 SeString 负载。

### SeString​

这个类表示一个解析后的 SeString。

### SeStringBuilder​

使用构建者模式构建 SeStrings 的辅助类。

## 接口

### ITextProvider​

一个接口绑定，用于提供可读文本的负载。

## 枚举

### BitmapFontIcon​

这个类表示可以自然出现在聊天中或作为 IconPayloads 的特殊图标。

### Payload.EmbeddedInfoType​

这表示负载中嵌入信息的类型。

### Payload.SeStringChunkType​

这表示负载的类型及其编码方式。

### PayloadType​

所有解析后的 SeString 负载类型。
