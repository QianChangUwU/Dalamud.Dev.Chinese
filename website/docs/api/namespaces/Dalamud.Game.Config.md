# Dalamud.Game.Config

> 🌐 本页是 [dalamud.dev/api/Dalamud.Game.Config/](https://dalamud.dev/api/Dalamud.Game.Config/) 的中文翻译。
> 类型/方法名称保留英文原文，仅翻译说明文字。

## 类

### ConfigChangeEvent​

表示配置中的更改。

### ConfigChangeEvent&lt;T&gt;​

表示配置中的通用更改。

### ConfigOptionNotFoundException​

当配置部分中不存在匹配的配置选项时抛出的异常。

### FloatConfigProperties​

表示一个浮点配置属性。

### GameConfigOptionAttribute​

用于定义 GameConfig 选项的属性。

### GameConfigSection​

表示游戏配置的一部分，并包含用于访问和设置值的辅助函数。

### IncorrectConfigTypeException​

当尝试将值分配给错误类型的配置选项时抛出的异常。

### StringConfigProperties​

表示一个字符串配置属性。

### UIntConfigProperties​

表示一个无符号整数配置属性。

## 枚举

### ConfigType​

游戏配置中使用的选项类型。

### PadButtonValue​

Dalamud.Game.Config.SystemConfigOption 下 PadButton 选项的有效值。

### SystemConfigOption​

系统部分的配置选项。

### UiConfigOption​

UiConfig 部分的配置选项。

### UiControlOption​

UiControl 部分的配置选项。
