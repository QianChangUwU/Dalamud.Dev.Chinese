# Dalamud.Interface.FontIdentifier

> 🌐 本页是 [dalamud.dev/api/Dalamud.Interface.FontIdentifier/](https://dalamud.dev/api/Dalamud.Interface.FontIdentifier/) 的中文翻译。
> 类型/方法名称保留英文原文，仅翻译说明文字。

## 类

### DalamudAssetFontAndFamilyId​

表示来自 Dalamud 资源的字体。

### DalamudDefaultFontAndFamilyId​

表示默认的 Dalamud 字体。

### GameFontAndFamilyId​

表示来自游戏的字体。

### SingleFontSpec​

表示用户选择的单一字体。

### SystemFontFamilyId​

表示来自系统的字体。

### SystemFontId​

表示安装在系统中的字体。

## 接口

### IFontFamilyId​

表示字体系列标识符。并不打算供插件实现。

### IFontId​

表示字体标识符。并不打算供插件实现。

### IFontSpec​

表示用户选择的字体。并不打算供插件实现。

### IObjectWithLocalizableName​

表示具有可本地化名称的对象。
